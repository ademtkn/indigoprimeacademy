Yönetim Paneli

Sitedeki metinleri, menüyü, öğretmenleri, haberleri ve resimleri buradan değiştirebilirsiniz.

Erişim anahtarını nasıl alırım?
  1. GitHub'a ademtkn hesabıyla girin.
  2. Settings → Developer settings → Fine-grained tokens → Generate new token sayfasını açın.
  3. Token name: “Site admin”. Expiration: örneğin 1 yıl.
  4. Repository access: Only select repositories → indigoprimeacademy.
  5. Permissions → Repository permissions: Contents: Read and write ve Actions: Read-only.
  6. Generate token'a basın, çıkan anahtarı kopyalayıp buraya yapıştırın.

Anahtar yalnızca bu tarayıcıda saklanır. Başka birine yetki vermek için ona ayrı bir anahtar oluşturun; kaybolursa GitHub'dan silin.
